Database & Safe Place Settings

Protect your records from browser history clearing

Why does clearing browser history remove data on GitHub Pages?

GitHub Pages (github.io) is a static website host. Without a cloud database connected, data entered on GitHub Pages is saved in your browser temporary storage. Clearing browser history wipes that storage.

Permanent Safe Place Options:

1 Run on your PC with Local SQLite Database (100% Safe)

Run START_KHODAL_OFFICE.bat on your PC. It saves everything permanently to D:\Khodal_info\data\khodal_office.db. Clearing browser history will NEVER delete your records!
